# Evow Edumanequin

Website company profile untuk Evow Edumanequin - Inovasi alat edukasi RJP (Resusitasi Jantung Paru) untuk Indonesia tanggap darurat.

## Tech Stack

- React 19
- TypeScript
- Tailwind CSS v4
- Framer Motion
- Vite

## Cara Menjalankan

**Prasyarat:** Node.js

1. Install dependencies:
   ```bash
   npm install
   ```
2. Jalankan development server:
   ```bash
   npm run dev
   ```
3. Buka browser di `http://localhost:3000`

## Build Production

```bash
npm run build
```

## Struktur Folder

```
src/
├── assets/          # Gambar, logo, dan media
├── components/      # Komponen React (Navbar, Hero, About, dll)
├── App.tsx          # Root component
├── main.tsx         # Entry point
└── index.css        # Global styles
```
